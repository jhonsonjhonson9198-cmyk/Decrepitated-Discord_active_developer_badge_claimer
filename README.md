# Discord_active_developer_badge_claimer
This repo is a simplistic bot to claim the active developer badge on discord.

# Prerequisites
You must have node.js installed : https://nodejs.org

and also discord.js : `npm i discord.js` in the console

# Installation and use
## Installation
Create a bot on Discord developers by following this article : https://discord.com/developers/docs/quick-start/getting-started

Install the project : `git clone https://github.com/cpascarlos/Discord_active_developer_badge_claimer.git` 

Replace "BOT-TOKEN" with your bot's token (available from discord developers) in config.js
```js
    token : "BOT-TOKEN" // (put your token in config.js)
```

## Use
Now put the bot on one of your servers (the server must have the community enabled)

Start the bot by doing `node main` in the console while located in the project folder

Run the /enable command and wait **24 to 48 hours**

Claim your badge at https://discord.com/developers/active-developer
